# Projects that survive interruption without forcing completion

**October 18, 2026 — experimental opt-in prototype**, stacked on the unified physical-home PR #34.

Pretorius needs freedom to begin something, change his mind, spend time reading or simply rest, and resume weeks later without being compelled by a daily task list. A project is **his declared intention and evolving reflections**, not a fabrication that a physical experiment occurred.

## World and cognition are not the same thing

The Laboratory retains *objective physical source state* in the existing embodied, domestic, book, material, arrangement and rhythm event ledgers. `PersonalProjects` is a separate, additive **prospective intention/commitment ledger** inside the same SQLite world; it does not own the chair, book, paper, specimen, apparatus or clock.

The author of a project explicitly supplies their text at the subject/action boundary. `start` records one new intended activity; `reflect` adds exactly supplied words; `pause` and `resume` are explicit decisions; `abandon` preserves history but ends pursuit; `finish` records only **self-declared completion**, explicitly not verified scientific success. `review` permits a voluntarily requested first-person recollection of the record. No invisible automatic resumption, inferred reward or mandatory goal.

Each voluntary project decision gets a real event receipt under the established world identity, genuine body station and actual historical world-clock revision. The project ledger's source envelope, before/after digests and append-only event hash are independently replayed. For `associate`, the source must be an actual already committed event from an explicit supported physical domain; receipt hashes are verified against their original source and the physical owning domain is independently replayed. **An association is not proof of completion or of causation**; it means that Pretorius connected a specific real occurrence with an intention.

## A meaningful interruption trial

1. At the real Laboratory threshold, explicitly begin an idea in first-person authored prose, e.g. `Study the influence of steam on glass condensation`.
2. Walk to the workbench, carry out a *real* supported experimental action and explicitly associate its real world receipt with the intended project.
3. Pause the project. The apparatus's world condition is still governed by the real rhythm/material system, while the planned work stays recorded without autonomous advancement.
4. Do something else: open an actual source-backed book, advance to page two and physically mark it, then leave the book; write an unrelated note on actual source-verified paper.
5. Advance **42 actual four-hour world events** to span seven simulated days. Project status remains paused and experiment count stays unchanged; the existing volume's bookmark and exact written words remain intact.
6. On returning, the intention can be reviewed; `resume` requires a **new explicit subject-selected action**. The simulation must not resume on sight or force a second experiment.

This is not a complete seven-day *autonomous self-directed* trial. The test author explicitly selects actions and supplies free text in the fixtures. It proves the physical and prospective structures behave reliably **if a real Doctor-renderer chooses those things**. The separately connected [Doctor branch](https://github.com/Azimn/The-Doctor-Lives/pull/82) verifies those subject-supplied intentions enter the established first-person memory inlet rather than a second artificial identity or made-up autobiography.

## Intervention and safety expectations

- Subject sees only ordinary first-person text. Engineer object IDs, raw world clocks, numeric needs, receipts and SQLite are not a subject-language substrate.
- An old offer ID is invalid when any of the genuine underlying world/book/project conditions change. No automated project action may be executed without the new source-validated offer.
- Asking to do something unsupported yields no claim it happened. A fantasy description is not a physical receipt. Project intentions do **not** move the chair or run an experiment merely by being recorded.
- Physical event evidence is not invented: only exact committed original event hash and event ID may be associated. Tampering physical or project records fails replay.
- A retry with the same project action event ID and payload is idempotent. Reusing that ID for a different choice is prohibited.
- Project world forks inherit selected *current intention state* as a branch starting point, but **not parent lived project events or associated parent-world physical receipts**; a fork must not claim to have witnessed the parent's original experience.
- Project names/reflections do not auto-surface as an omniscient scene description. They are an explicit reviewing activity, and should not substitute for the Doctor's own imperfect personal memory.

## Next necessary step to claim stronger autonomy

A Doctor subject must **itself generate** an intention and decide whether to act, pause or resume, rather than the host writing its intention for it. The existing recurrent neural controller offers generic action tendencies and did not demonstrate a neural advantage over a cheap equally informed rule controller in earlier tests. A suitable future `Intention Proposal` port should accept actual renderer-produced first-person language, distinguish expressed *intent* from verified *execution*, match real action affordances without assuming success, and submit a real world action only following subject selection.

Then do a blinded multi-seed, multi-day trial where the Doctor is never required to choose any particular activity. Evaluate actual world receipts, dormant unfinished projects, interruptions, days spent entirely elsewhere, and properly resurfaced commitments. Compare an equally informed cheap agent before claiming any neural or individual behavioral benefit.

This experiment **does not** advance the Article 7/8 gates, prove intrinsic motivation or deploy new state into an inhabited canonical world. It is a reversible research branch dependent on PR #34's unmerged world overlay.
