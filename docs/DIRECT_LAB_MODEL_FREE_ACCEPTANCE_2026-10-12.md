# Direct laboratory acceptance independent of Pretorius's model

Date: October 12, 2026 (America/Chicago).
Scope: new isolated research world, not the canonical Pretorius state.
First verified CI: https://github.com/Azimn/Pretorius-Laboratory/actions/runs/38210252425
Executable: examples/direct_lab_session.py

## Why

A weak model is not a valid test of physical simulation capability. This acceptance session uses the existing real subject-facing EmbodiedAccess port but removes all language-model and neural decision-making. A researcher chooses concrete actions. Any engineer-only intervention is explicitly labelled and not credited to the subject.

## Verified direct result

The CI run completed 19 recorded stages. Six illegal actions were denied without changing the physical, body, custody, book or instrument ledger revisions. Nine terminal physical-history verification gates passed. The preexisting unittest regression suite also passed, 122 out of 122.

The actor could not see instruments or distant titles at the threshold, read a remote book, or teleport directly to a shelf. It walked to the bench and weighed the source-bound synthetic beaker, receiving a 325 g readout with a 312 to 338 g uncertainty interval. Reusing the measurement event ID produced the identical historical reading without a new event.

At the third shelf it read a stored synthetic source page, marked the second page, picked up the book and verified that shelf occupancy was genuinely vacant. A second simultaneous pickup was rejected, as was trying to put the book onto the still-occupied bench. The researcher then used a privileged operator action to relocate the beaker onto the floor. That staging was not a character decision. The subject placed its held book on the newly empty bench and measured the physical book's quantized mass and width.

After reopening, the actor was still at the bench and the saved bookmark restored the exact second source page. A verified backup preserved all three measurement events. A sandbox fork inherited the actor pose and current book placement but had a distinct world epoch and no newly claimed instrument experiences. Moving the book to the shelf in the fork did not change its bench placement in the parent.

A separate physical fixture retained beaker damage and denied relocation until glass fragments were collected. A deliberately tampered copy of a measurement event failed verification. The original verified database was not modified by that negative check.

## What passes and what remains unproved

This establishes functioning discrete world authority for nearby perception, movement graphs, single-object custody, occupied surfaces, reading/bookmarks, source-bound bounded measurements, replay, backups, forks and damage transitions.

It does not establish continuous 3D physics, physical hands, richer free-form object affordances, spontaneous cognitive activity, learned character skills or self-directed recall. The independent fixture has seven physical books and a beaker, only one installed two-page synthetic edition, and engineered mass/size assumptions. The separate full-text corpus fixture supports seventeen titles. This direct scenario does not test that corpus.

The simulated actor's controls are real; its action decisions in this test are experimenter-scripted. No canonical Doctor Lives memory, The-Doctor-Lives production code or Frankenstein Village world was changed.

## Repeat

From the cloned repository with Python 3.10 or newer, run:

    python examples/direct_lab_session.py --output /tmp/direct-lab

The target folder must be empty. The script outputs a scored direct-session-report.json and isolated world, backup, fork and damage SQLite databases. No downloaded language model, paid API or server is required.

Recommended next validation: task diversity and a researcher-authored competent controller using only the same bounded subject-facing tools. Keep the simulator and the cognitive controller separately scored, and use a new sealed world/task set before making claims of behavioral generalization.
